# Submit an edit as a pull request

Use this workflow when you edit docs in DraftView and want to open a PR directly.

## Steps

<wc-steps>
<wc-step title="Open the source page in DraftView">

Open DraftView with the source file URL in the `url` query parameter.

</wc-step>
<wc-step title="Edit content">

Make your changes in the visual editor.

</wc-step>
<wc-step title="Authenticate with GitHub">

If needed, DraftView asks you to sign in with GitHub.

</wc-step>
<wc-step title="Create fork, commit, and PR">

DraftView guides you through fork creation, commit, and PR submission.

</wc-step>
</wc-steps>
