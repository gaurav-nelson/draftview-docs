# Move from Word Track Changes

Use this migration path when your team still reviews docs through exported Word files.

## What changes in your process

- Stop exporting docs for review rounds.
- Keep review in the pull request lifecycle.
- Use DraftView to make edits and comments in context.
- Push final feedback to GitHub as suggestions.

## Suggested rollout

1. Pick one recurring docs workflow.
2. Route that workflow through DraftView review and sign-off.
3. Use external links for reviewers who are not in GitHub.
4. Retire Word-based review for that workflow.

## Benefits after migration

- Fewer copy and paste errors
- Clear lifecycle state per PR
- Consistent audit trail for sign-off
