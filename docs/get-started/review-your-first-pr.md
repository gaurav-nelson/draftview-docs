# Review your first pull request

This walkthrough covers one end-to-end docs review with the same human checkpoint used in AI-generated docs workflows.

## Prerequisites

- You can sign in to DraftView.
- You have access to the target PR in GitHub.
- The PR changes supported doc file formats.

## Steps

<wc-steps>
<wc-step title="Sign in">

Sign in at [https://www.draftview.app/login](https://www.draftview.app/login).

</wc-step>
<wc-step title="Open a PR">

Paste the PR URL in the dashboard, or open the direct route:

```text
https://www.draftview.app/github.com/owner/repo/pull/123
```

</wc-step>
<wc-step title="Review the content">

Read the rendered docs in the center pane. Move between files in the file list, and use comments or edits where needed.

</wc-step>
<wc-step title="Submit your review">

Submit comments and suggested edits. DraftView maps your feedback to the PR in GitHub.

</wc-step>
<wc-step title="Verify follow-up commits">

If the author or AI agent pushes a revision, compare updates against your previous feedback and confirm resolution.

</wc-step>
</wc-steps>
